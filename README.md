# Structural Integrity

Block integrity and collapse for NeoForge 1.21.1. Every structural block carries an
integrity value (nireg); placing charges the structure under it, breaking relaxes it,
and a component that loses its path to ground is handed to sable as a physics
sub-level, reverting to blocks when it lands.

## Tuning block integrity (nireg)

Per-block values are a **NeoForge data map**, not a TOML config:

```
data/structuralintegrity/data_maps/block/natural_integrity.json
```

The jar ships a small table of exceptions; any block without a row derives its value
from mining hardness (`defaultIntegrity * sqrt(hardness / 1.5)`, so stone-hardness
lands exactly on the default of 24; unbreakable = 1024, zero-hardness = fragile).

### Editing values live (no restart)

Put an override datapack in the world, or with Paxi installed in:

```
<profile>/config/paxi/datapacks/integrity_tuning/
  pack.mcmeta
  data/structuralintegrity/data_maps/block/natural_integrity.json
```

Rows merge over the shipped table - list only what you change, then run `/reload`
in game. Row format:

```json
{
  "values": {
    "minecraft:cobblestone":    { "integrity": 20 },
    "#minecraft:wooden_fences": { "integrity": 9, "never_anchor": true }
  }
}
```

`never_anchor: true` means the block can never count as untouched ground.

### Selecting modded blocks

Data map keys accept **exact ids or `#tags` only** - there is no glob/wildcard
support in NeoForge (`create:*_casing` is rejected by the parser). To cover modded
blocks:

- **Use tags.** Tags are the intended wildcard: `#minecraft:planks`,
  `#minecraft:logs`, `#c:ores`, `#c:storage_blocks` etc. catch every modded block
  registered into them, including blocks from mods installed later.
- **Define your own tag** in the same datapack
  (`data/<namespace>/tags/block/<name>.json` listing the ids) and reference it with
  one datamap row.
- **Rely on the fallback.** Any modded block with no row still gets a
  hardness-derived value, so nothing is ever untracked.

- **Use config patterns** (0.5.16+). `integrityPatterns` in
  `structuralintegrity-server.toml` takes `"<id-pattern>=<integrity>"` entries
  where `*` matches any run of characters in the full id:

  ```toml
  integrityPatterns = ["create:*_casing=40", "mekanism:*_ore=34"]
  ```

  First matching entry wins. Precedence: datamap row > pattern > hardness
  derivation. Applies live on file save - no restart, no /reload.

### Scalar knobs

`config/structuralintegrity-server.toml` holds the non-per-block settings:
default/fragile integrity, fail floor, hardness derivation toggle, material
boundary rule, clump bracing, snap side selection, assembly limits. NeoForge
watches the file, so edits apply on save.

### Full census

`integrity-sweep.csv` (repo root, regenerated by the `integritySweep` gametest via
`./gradlew runGameTestServer`) lists every vanilla block with its resolved value,
never_anchor flag, source (datamap/derived) and structural classification.
